# Earthroot Farms - Public Storefront

Public customer storefront for **Earthroot Mushrooms** and **Poultry Farm**.

## Features
- **Mushroom Storefront:** `index.html` (`/`)
- **Poultry Farm:** `poultry.html` (`/poultry`)
- **Real-Time Stock Sync:** Cloud Firebase listener automatically reflects available harvest stock.

## Running Locally
```bash
node server.js
```
Runs at: http://localhost:3001
