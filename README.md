# Earthroot Mushrooms 🍄🌿

A modern, responsive, and elegant website for **Earthroot Mushrooms** — organically cultivating gourmet and medicinal mushrooms straight from the farm in Pullurampara, Thiruvambady, Kozhikode, Kerala.

## ✨ Features

- **Gourmet & Medicinal Catalog**: Browse varieties including Pearl Oyster, Milky Mushrooms, White Button, and Lion's Mane.
- **Interactive Cart & WhatsApp Checkout**: Add packs to order and generate a formatted WhatsApp order confirmation message with total estimate.
- **Local PIN Code Eligibility Checker**: Instant validation for delivery coverage across `67360x` pincode regions.
- **Farm Story & Process Timeline**: Showcase organic cultivation practices and HEPA-filtered clean room technology.
- **Culinary Inspiration**: Handpicked Kerala-style recipes for gourmet dishes.
- **Responsive & Modern Design**: Clean UI with Poppins typography, rich colors, and smooth micro-interactions.

## 🛠️ Built With

- **HTML5 & Vanilla CSS3** (Custom Design Tokens, Flexbox, CSS Grid)
- **Vanilla JavaScript (ES6+)**
- **Google Fonts (Poppins)**
- **FontAwesome 6**

## 🚀 Live Preview / Setup

To run locally, simply open `index.html` in any web browser or use a live server extension.
